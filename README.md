# Replay Scout

Paste Duelingbook replay links, get the decklist image, RPS and a text summary of a player, ready for Discord.
Made for tournament scouting. Not affiliated with Duelingbook.

## Install

- **Chrome, Brave**: open the [Chrome Web Store page](https://chromewebstore.google.com/detail/replay-scout/bfpkapibhhijiomeelbomnkfiggoklnl) and click **Add to Chrome**.
- **Edge**: open the same link; the first time Edge asks to allow extensions from other stores: allow it, then **Get**.
- **Firefox**: open the latest `.xpi` from [Releases](https://github.com/EdoTiso/replay-scout/releases/latest) **in Firefox** and click **Add**.
  If you downloaded it with another browser, drag the file into a Firefox window.

Updates are automatic on every browser.

Then pin the icon: click the puzzle piece in the toolbar and the pin next to Replay Scout.

## Use

1. Click the Replay Scout icon. It opens Duelingbook if needed, and the panel on the right.
2. Paste the replay links. Any text around them is fine (e.g. `Round 2 vs Marlo: https://www.duelingbook.com/replay?id=...`). Up to 20 links.
3. Press **Rebuild**. If a Cloudflare checkbox appears on the page, click it.
4. Pick the player, then **Copy image** / **Copy summary** (results and RPS as text, shown at the bottom of the panel) and paste into Discord, or **Download**.
